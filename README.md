Pada studi kasus kali ini, saya membuat program yang dijalankan untuk menghitung tarif biaya parkiran di suatu tempat. Saya menggunakan 3 jenis input, mulai dari jenis kendaraan, jam masuk dan jam keluar untuk menjalankan program.

## KODE ##

<img width="551" height="190" alt="image" src="https://github.com/user-attachments/assets/78da29fb-2754-42f4-9f8a-082df2b74b9f" />

Disini, saya menggunakan kode function seperti yang baru saya pelajari, untuk menghitung biaya, harus ada jenis kendaraan dan durasi parkir. Jika jenis kendaraan adalah mobil, maka tarifnya adalah 5000/jam, dan motor 3000/jam, selain dari itu maka tidak diketahui. Untuk menentukan total biaya, diperlukan operator tarif dikali dengan durasi, kemudian dipanggil dengan menggunakan kode return. Kemudian saya memasukkan kode untuk user menginput jenis kendaraan, jam masuk dan jam keluar, kemudian durasi dihasilkan dari operasi jam keluar dikurang jam masuk. Setelehnya total adalah hasil dari jenis kendaraan dan durasi.
